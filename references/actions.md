# 动作与画质策略

默认模型 gpt-image-2，quality high；参考角色、实际返回尺寸及调用能力必须记录。1024×1024 用于基础形象、眼睑、探头和单姿势；2048×1536 用于 4列×3行图集。代理可能返回其他尺寸，不能把请求尺寸写成实际尺寸。保存原图，最终输出 512×512；不要在中间降到 384 再放大。处理器目前固定 512，修改尺寸需要另行验证。

| 程序动作 | 生图内容 | 处理/播放 |
|---|---|---|
| idle 待机 | 精确脸部裁剪，2×2 四个眼睑阶段；只改眼睑 | 配准后只贴眼区，80帧/20fps；身体固定，运行时约0.3%四秒呼吸 |
| walk 移动 | 四足12相位图集；双足12张单图，近远腿换支撑；无腿主体可本地漂浮 | 12真实关键姿势插值成24帧/20fps，包含末帧→首帧 |
| peek 探头 | 单张终点姿势，身体藏在左边界，头向右探，胸肩斜连，腰部隐藏 | 42帧/24fps，侧向弹簧展开；不是直立胸像平移 |
| drag 抱起 | 12阶段图集，想象胸腹及后躯被托住，爪自然放松 | 12帧/12.5fps，可循环；不扯颈、不拉长身体、不渲染手 |
| send 带包裹移动 | 与真实步态一致，包裹用实际附肢或合适挂带携带 | 24帧/20fps循环，不额外加人手 |
| unpeek 缩回 | 不新生图 | peek 精确倒放 |
| edgehide 边缘停留 | 不新生图 | peek 最后一帧 |
| speak 说话 | 不新生图 | 基础静态，不做嘴部循环 |

没有实际眼睛时 idle 可 static；刚性灯光主体可 local-signal，不能凭空画眼睛。只有有机主体才默认微呼吸，刚性机器人不呼吸。已经承诺眨眼但配准失败时须报告失败，不能静默换成静态。

基础 prompt 应明确：同一个个体，目标风格，原有胖瘦/毛长/面部特征，完整身体耳尾脚爪，充足空白；纯 #00FF00 背景，无地面/影子/文字。选择拟人站姿时可调整重心和前爪位置，但不加人类胳膊、鞋或手掌。毛绒效果用丰富细毛、柔软毛束、细碎轮廓、柔和光照表达，保留目标猫短毛/长毛区别，不能把短毛都改成长毛。

prepare 工具产出的 prompt 已含动作契约及版式引导。identityRefs 中首先放标准化确认基础图（role confirmed-base），随后才是用于细节的原始照片（identity-detail）。姿势图标明 pose-only，并检查它是否符合该动作；一般动作不要加入无关姿势图。待机只提供 exact-face-only 裁剪，不提供全身图。图集每格身体及全部配件占宽高最多60%，四边至少20%空白，格间必须真有背景间隙；模型画出的分隔线和标签都不需要。
